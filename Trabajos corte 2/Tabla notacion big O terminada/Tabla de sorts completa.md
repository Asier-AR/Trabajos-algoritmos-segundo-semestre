

Tabla de complejidad





|Tipo de busqueda|Que hace|Complejidad|
|-|-|-|
|Insertion sort|Inserta los elementos mas grandes a la derecha mientras recorre la lista|0(n al cuadrado)|
|selection sort|recorre la lista y coloca los elementos mas pequeños al principio|O(n al cuadrado)|
|bubble sort|Recorre el arreglo elemento por elemento y compara el vecino ed (arr\[0]>arr\[1])|O(n al cuadrado)|
|quick sort|Dependiendo de como este construido pero generalmente usara un pivote como una base de medición para dividir el arreglo hasta que no se pueda dividir mas o también puede modificar la lista directamente usando una función llamada partición |On\*(log n)|
|heap sort|organiza los elementos de una lista o arreglo de manera ascendente o descendente utilizando una estructura de datos llamada montículo (o heap), que es un tipo de árbol (me falta preguntarle a la profe por mas informacion)|0(n\*log n)|
|bucket sort|Crea una lista que contiene n cantidad de listas y en cada una de sus listas internas va a recopilar los elementos, (los elementos mas pequeños irán en la cubeta\[0] y los mas grandes en la cubeta\[n])|O(log n\* n) o O(log n)|
|merge sort|Divide el arreglo múltiples veces para después reorganizarlo|O n\* (log n)|
